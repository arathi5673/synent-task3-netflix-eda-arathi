# Task 3 - Netflix Exploratory Data Analysis (EDA)

## Problem Statement
Identify trends and patterns in the Netflix 
dataset using Exploratory Data Analysis.

## Dataset
- Name: Netflix Shows Dataset
- Source: Kaggle
- Shape: 8807 rows, 12 columns
- Features: show_id, type, title, director, 
  cast, country, date_added, release_year, 
  rating, duration, listed_in, description

## Approach
- Loaded Netflix dataset using pandas
- Checked missing values and summary statistics
- Analyzed Movies vs TV Shows distribution
- Found Top 10 countries with most content
- Analyzed content trend over years
- Analyzed top ratings
- Found top 10 genres
- Identified key trends and patterns

## Key Insights
- Total content: 8807 titles
- Movies are more than TV Shows on Netflix
- USA produces the most content
- TV-MA is the most common rating
- Content increased significantly after 2015
- International Movies is the top genre
